Worklog

This worklog documents my 12-week internship journey (08/09/2025 - 08/12/2025) with the AWS First Cloud Journey (FCJ) program, during which I developed SIAM (Smart Industrial Asset’s longevity Monitor) - a hybrid edge-cloud platform for predictive maintenance using AWS IoT services.

The project leverages AWS IoT Greengrass for edge computing on a Raspberry Pi 5, combined with a serverless cloud backend utilizing Lambda, DynamoDB, S3, SageMaker, API Gateway, EventBridge, and CloudWatch. The system demonstrates real-time anomaly detection using a Coral TPU for ML inference at the edge, with automated model retraining and deployment through a complete MLOps pipeline.

Throughout this internship, I completed hands-on learning of core AWS services, prototyped IoT solutions with ESP32 and sensors, designed the full system architecture, implemented automated infrastructure deployment scripts, and built an end-to-end solution that combines edge intelligence with cloud scalability.

Weekly Breakdown

Week 1: Getting familiar with AWS FCJ program and foundational AWS services

Week 2: Learning AWS IoT Core, MQTT, and ESP32 prototyping

Week 3: Cloud infrastructure setup and AWS automation scripts

Week 4: EC2, VPC networking, and Raspberry Pi provisioning

Week 5: Local data collection and sensor integration

Week 6: Initial ML model training with SageMaker

Week 7: AWS IoT Greengrass setup and component development

Week 8: Full pipeline integration with Stream Manager and Docker

Week 9: MLOps automation with EventBridge and Lambda

Week 10: API Gateway security, rate limiting, and authentication

Week 11: Web dashboard development and system testing

Week 12: Final testing, documentation, and project completion
