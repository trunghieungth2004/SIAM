SLIDE 4: TECHNICAL ARCHITECTURE
===============================================================================
Hybrid Edge-Cloud Platform

EDGE LAYER:
• Raspberry Pi 5 + Google Coral TPU (AI acceleration)
• Sensors: MPU-6050 (vibration), INA219 (current), DS18B20 (temp)
• AWS IoT Greengrass (secure edge runtime)
• Docker containers (ML inference)
• Stream Manager (offline buffering)

CLOUD LAYER:
• AWS IoT Core (device connectivity)
• Lambda Functions (serverless processing)
• DynamoDB (real-time data storage)
• SageMaker (automated ML training)
• API Gateway (secure REST API)
• EventBridge (bi-weekly retraining)
• SNS (notification service)
• CloudWatch (monitoring & alarms)

DATA FLOW: Vibration Sensors → Edge AI → Cloud Analytics → Dashboard
ALERTS: CloudWatch Alarm → SNS Topic (requires email subscription)

SLIDE 6: FUTURE IMPROVEMENTS - HUB & SPOKE MODEL
===============================================================================
Proposed Scalable Architecture

CURRENT SETUP:
• Pi directly connected to sensors on 1 machine
• Cost: $187 per machine

FUTURE (Hub & Spoke):
• Multiple ESP32s with sensors (1 per machine)
• Each ESP32 transmits data to central Pi hub
• Pi aggregates all data and handles AWS communication
• Single Pi serves entire facility

ARCHITECTURE:
ESP32 #1 (Motor) ──┐
ESP32 #2 (Pump) ───┤
ESP32 #3 (Fan)  ───┼──→ Raspberry Pi Hub ──→ AWS
ESP32 #4 (Comp) ───┤
ESP32 #5 (Motor) ──┘

COST REDUCTION:
• ESP32 + sensors: ~$10 each
• 10 machines: $100 (ESP32s) + $187 (Pi) = $287 total
• Current: $1,870 (10 × $187)
• Savings: 85% reduction
